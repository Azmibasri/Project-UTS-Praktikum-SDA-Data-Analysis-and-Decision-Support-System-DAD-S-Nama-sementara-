# Project-UTS-Praktikum-SDA-Data-Analysis-and-Decision-Support-System-DAD-S-Nama-sementara-
DAD'S adalah sebuah software yang dibuat sebagai syarat pemenuhan tugas UTS pada mata kuliah Praktikum Strukutur Data dan Algoritma. dengan fitur analisis data sebagai alat pembantu pembuat keputusan, yang modular dan berbasis Command Line.
